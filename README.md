# Handbook of the chair's research platform

The platform keeps code on GitHub and data on Dropbox, and Claude does the technical steps when you ask.

## New here? Do these three things

1. [Set up your machine](start/set-up-your-machine.md), once.
2. Work through [Your first day](start/first-day.md) on your practice project.
3. Keep [the daily routine](researcher/daily-routine.md) open while you work.

[Words](reference/words.md) explains each term, such as clone, pull, step, pin and exhibit.

## How to read this handbook

- A name in angle brackets stands for your own, as in `<project>` or `<you>`.
- **Ask Claude.** names the repo: open the session on that repo's top folder.
- **Untested on Windows.** marks a step that nobody has yet tried on a university Windows machine.
